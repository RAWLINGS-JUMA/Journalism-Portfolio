# IMPLEMENTATION PLAN
## Professional Broadcast Journalist Portfolio Website

**Project Type:** Personal Professional Portfolio Website  
**Target User:** Second-Year Journalism Student – Broadcast Journalism  
**Development Approach:** Responsive, Multi-Page Frontend Website  
**Development Tool:** OpenCode

---

# 1. PROJECT OVERVIEW

### 1.1 Project Description

The project involves designing and developing a modern, professional and responsive personal portfolio website for an emerging broadcast journalist who is currently pursuing her second year of journalism studies.

The website will serve as her professional digital identity, providing a central platform where visitors, media organisations, potential employers, internship coordinators, mentors and collaborators can learn about her background, explore her journalism work, assess her skills and establish professional connections.

The website must communicate professionalism, creativity, credibility and an interest in broadcast journalism.

Although the owner is still a university student, the design and presentation should reflect a polished professional media portfolio without exaggerating her qualifications, experience or achievements.

### 1.2 Main Objectives

The website should:

1. Establish a strong professional online identity.
2. Showcase her broadcasting, reporting, interviewing and multimedia production abilities.
3. Present her educational background and journalism-related competencies.
4. Display her academic projects, practical assignments and media productions.
5. Provide access to her written publications and multimedia content.
6. Attract internship opportunities, professional collaborations and mentorship.
7. Provide convenient access to her CV and professional contact information.

---

# 2. PROJECT SCOPE

The project will be developed as a public-facing, multi-page website.

### 2.1 Website Architecture

The website will have six primary navigation items:

1. Home
2. About
3. My Work
4. Skills & Education
5. Achievements
6. Contact

All related content will be organised as subsections within the appropriate pages.

A separate Download CV button will be included in the main navigation or header.

### 2.2 System Limitations and Exclusions

The initial implementation will not include:

- User registration or login.
- Authentication and authorisation.
- Administrator dashboard.
- Database integration.
- PHP or other backend application logic.
- User account management.
- Content management system.

The website will use static frontend content and external services where necessary, such as YouTube for video hosting and an external form service for contact submissions.

OpenCode should use the following technologies:

| Technology | Purpose |

| HTML5 | Website structure and semantic markup |
| CSS3 | Custom styling and visual presentation |
| JavaScript | Interactivity and dynamic frontend behaviour |

The website must be deployable using ordinary static web hosting.

# 4. WEBSITE DESIGN AND VISUAL IDENTITY

### 4.1 Design Direction

The website should follow a premium corporate and editorial design approach.

The visual identity should combine the appearance of a modern media organisation with the personal branding of a broadcast journalist.

The design should be:

- Professional and elegant.
- Modern and visually appealing.
- Minimal but not empty.
- Editorial in presentation.
- Consistent across all pages.
- Easy to navigate.
- Responsive across different screen sizes.

Avoid excessive animations, unnecessary decorative elements, overcrowded sections and generic student portfolio templates.

### 4.2 Colour Scheme

Use the following proposed colour palette:

| Colour | Hexadecimal | Application |
|---|---|---|
| Deep Navy | #101C2C | Primary backgrounds and navigation |
| White | #FFFFFF | Main backgrounds and text contrast |
| Gold | #D6B56D | Accent elements and highlights |
| Light Grey | #F2F3F5 | Alternate section backgrounds |
| Charcoal | #252B35 | Body text and secondary elements |

Gold should be used sparingly to maintain a sophisticated appearance.

### 4.3 Typography

Use a combination of elegant serif headings and clean sans-serif body text.

Recommended fonts:

- Playfair Display – Main headings.
- Inter – Body text and navigation.
- Lato – Optional supporting typography.

Typography should maintain a clear hierarchy between page titles, section headings, descriptions, captions and buttons.

### 4.4 Photography and Visual Content

Use professional photography throughout the website.

Priority should be given to:

- Her actual professional portrait.
- Journalism-related photographs.
- Reporting and interview photographs.
- Broadcast studio photographs.
- Actual video thumbnails.
- Relevant academic and professional project images.

Do not use random stock photographs as representations of her actual professional activities.

Where personal photographs are not yet available, use clearly replaceable image placeholders.

The website must provide an excellent experience on:

- Desktop computers.
- Laptops.
- Tablets.
- Android smartphones.
- iPhones.

Implement mobile-first responsive layouts.

Pay particular attention to:

- Navigation behaviour.
- Image scaling.
- Video dimensions.
- Text readability.
- Section spacing.
- Card layouts.
- Button sizes.
- Contact form usability.

Avoid horizontal scrolling and overflowing content.

Test the website at common viewport widths, including approximately 375px, 768px, 1024px and 1440px.

### 9.2 Accessibility

Follow good accessibility practices:

- Semantic HTML5.
- Keyboard-friendly navigation.
- Appropriate colour contrast.
- Visible focus indicators.
- Descriptive image alternatives.
- Accessible form labels.
- Reduced-motion support.

### 9.3 Performance

Optimise the website by:

- Compressing images.
- Using WebP or AVIF where suitable.
- Lazy-loading below-the-fold images.
- Avoiding unnecessary JavaScript.
- Loading fonts efficiently.
- Using lightweight animations.
- Avoiding unnecessarily large background videos.
